# Showcase font

`plus-jakarta-sans-latin-wght-normal.woff2` is Plus Jakarta Sans as one variable font file
(weights 200 to 800), Latin subset: it covers English and Spanish.

- **Authors:** The Plus Jakarta Sans Project Authors (Tokotype),
  <https://github.com/tokotype/PlusJakartaSans>
- **License:** SIL Open Font License 1.1. `OFL.txt` is the license file of the package,
  unchanged.
- **Source:** the npm package `@fontsource-variable/plus-jakarta-sans` 5.3.0, file
  `files/plus-jakarta-sans-latin-wght-normal.woff2`, copied unchanged. The package is not a
  dependency: the file is served from this site by `next/font/local`, so no visitor's browser
  calls a font service.

The showcase pages (`src/app/(showcase)/`) are the only ones that use it. The brand's final
font is still open (#18, #30); Plus Jakarta Sans is one of the display candidates in
`docs/design/README.md`.
